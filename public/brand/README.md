# 5 Borough Boarders brand files

Traced to vector from the 320px Instagram logo. Put this folder at `public/brand/`.

| File | Use |
|---|---|
| logo-black.svg | Light backgrounds (header, cards). Transparent. |
| logo-white.svg | Dark backgrounds (footer, map overlays, hero photos). Transparent. |
| logo-badge.svg | Any background, including photos. Black logo on a white circle. |
| logo-currentcolor.svg | Inline SVG that takes the text color from CSS (`color:`), handy for hover states and theming. |
| logo-*-1024.png | PNG fallbacks (email, Instagram, merch mockups). |
| favicon.ico | Move to `src/app/favicon.ico`. |
| icon-192.png, icon-512.png | Web manifest icons. |
| apple-touch-icon.png | Move to `src/app/apple-icon.png`. |
